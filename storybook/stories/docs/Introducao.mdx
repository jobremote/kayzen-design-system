<H2>Para que serve</H2>

<P>
  O Kayene reúne o que é preciso para construir experiências de cuidado com calma e clareza: uma
  hierarquia de tokens precisa, componentes acessíveis e uma marca preservada. O tom é gentil e humano,
  sem virar ornamento nem ficar visualmente vago.
</P>

<H2>Usar em um produto</H2>

<P>Importe a interface pública e o tema uma única vez:</P>

<Code>{`import "@/design-system/kayene/styles/theme.css";
import { Button, TextInput } from "@/design-system/kayene";

<form className="grid gap-4">
  <TextInput label="Nome completo" name="name" />
  <Button type="submit" variant="primary">Continuar</Button>
</form>`}</Code>

<P>
  A variação visual vem das props documentadas (variant, size, status, state). Estenda um componente
  existente antes de criar um quase igual.
</P>
